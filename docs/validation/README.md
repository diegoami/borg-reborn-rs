# Validation receipts (archive)

Per-PR validation receipts, dossier maps and incident checks: how a
result was obtained at the time, with its build, configuration and log
hashes. They are **records, not current documentation**: read them to audit
an old claim, not to learn how the Borg works today. The contract for new
receipts is [VALIDATION-RECEIPTS.md](../VALIDATION-RECEIPTS.md) and
[REFERENCE-RECEIPTS.md](../REFERENCE-RECEIPTS.md); new gameplay evidence and
its receipts go to [borg-cemetery](https://github.com/diegoami/borg-cemetery).

**Moved here from `docs/` on 2026-11-21 (#816)** with `git mv`: the bytes,
and so every published hash, are unchanged, and `git log --follow` keeps
their history. Because they were not edited, **paths written inside them
are still the old ones**: a relative link resolves against `docs/`, and a
path such as `docs/P341-FRESH-DONOR-VALIDATION.json` (in these files, in
[harness/recipes/p341-full.json](../../harness/recipes/p341-full.json), in
handover notes and in published Cemetery packages) means the file of the
same name here. [`m13/`](m13/README.md) was already here.
