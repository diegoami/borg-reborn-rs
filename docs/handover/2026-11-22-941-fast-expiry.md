## #915 / PR #943 (kill_grouped_names)

They do not conflict, and neither depends on the other. #943 changes how a subject is resolved
to a race (`borg_guess_race_name` / `borg_locate_kill`, `borg_flow_kill.rs`). This PR changes
whether a message is taken as monster pain at all (`parse_monster_message`,
`borg_messages.rs`). With #941 on, "You feel yourself slow down." never becomes a PAIN reaction,
so it never reaches #943's code. "3 cave spiders slow down." does not start with "You feel ",
so it is still pain, and #943 resolves its subject. Their only overlap is textual: both add a
row after `kill_live_min_power` in `params.rs`, plus a `harness/borg.txt` block and a
`CALIBRATION.md` section. Whichever merges second keeps both rows and runs
`check-param-citations.py --fix`.
