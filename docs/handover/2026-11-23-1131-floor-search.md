## 2026-11-23 – Interrupted secret-door search on ordinary floor (#1131)

When a dark flow doubles back from a reached floor search target, it
counts the visit using the existing secret-door search budget for local
searches of up to two steps. The search records its final approach square
so it can detect the reversal at the target. Up-staircase visits use the immediate
reversal check from #1106.

The native fixture reproduces two steps west for the search and two east
for exploration. On unpatched `track-p`, a fifth search restarts the loop.
With the fix, four interrupted visits exhaust the level-17 search budget.

The checksum-verified owner save and action excerpts are retained in
the [Cemetery case](https://github.com/diegoami/borg-cemetery/tree/6dad97074c1e09b0e165d7036d6cde71b27dd06d/scenarios/paladin-floor-search-1955842).
The recorded headless reload stopped before issuing a key, so the
regression uses a constructed cave in the native harness.
