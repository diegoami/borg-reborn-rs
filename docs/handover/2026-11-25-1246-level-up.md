## 2026-11-25: Reach a character level and hand back in town (#1246)

`/level-up N` lets the default Borg play normally below the requested
current character level. On reaching the target it switches to the
ordinary town return, keeps that destination through experience drain, and
hands control back on arrival. Both phases use the same budget clock.
The shared command parser reports the 1–50 range for invalid targets.

Local checks cover Word of Recall after leveling, budget expiry while
returning, immediate completion in town, and the configured level-stop
precedence. A unit test covers the transition to town completion after a
level drain. The shipped profile still selects no errand.

The command follows the existing rules for class-phase plans and
`borg_stop_clevel`. An interactive errand cancels the plan, an automatic
errand conflicts with a configured plan, and an automatic character-level
stop still applies. The issue review and implementation PR cover these
choices. [Issue review](https://github.com/diegoami/borg-reborn-rs/issues/1246#issuecomment-7161529682)
