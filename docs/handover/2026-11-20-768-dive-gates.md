## 2026-11-20: C Borg dive gates (#768)

- Removed the character-level depth cap and its four parameters. Existing
  profiles with the retired settings load with a warning. The explicit
  `borg_plan` and `borg_no_deeper` limits still apply.
- Exposed the C preparedness gates with the C values compiled and shipped.
  A positive `prepared_clevel_depth_margin` allows deeper levels before CL50.
  The class offset first runs at DL10. Mage and Necromancer use a CL ceiling
  there, and the other classes use a depth ceiling.
- The source also has class HP and CL checks from DL5, class CL checks from
  DL21 and a minimum CL from DL34. These are exposed at the existing checks.
  The full parameter table and C citations are in [CALIBRATION](../CALIBRATION.md#c-borg-dive-gates-768).

  −2 / +2 and class-specific mid offsets against main's shipped cap. Record
  the per-class offset changes explicitly and keep the main control pinned.
