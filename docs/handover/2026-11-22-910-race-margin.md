## What was done

Two parameters, compiled and shipped 0 (today's race):

- **`caution_winning_fight_margin_percent`.** `winning_fight` uses
  `wins_race_margin`: it wins only when turns × incoming < (100 − margin)
  percent of the HP.
- **`caution_winning_fight_group_percent`.** A monster whose race has a
  `friends` or `friends-base` line counts 100 + this percent of its incoming
  damage (`group_scaled_incoming`).
- **The engine read.** The group test is a new engine read,
  `engine::race_has_friends`. It reads `r_info`'s friends pointers, game
  data, no monster state (fair information, RULES 11).
- **Tests.** Unit tests use the case's numbers.

## What was found
