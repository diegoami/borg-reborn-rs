## 2026-11-20 · Death-risk calibration (#790)

The native core records F1, F2 and F3 in `death_risk` on every traced think.
Dungeon samples use the existing `/stopscared` gate. Early returns and town
also get a sample, with `stop_eligible=false`. F1 uses the same danger and HP
as the gate. F2 uses expected plain HURT melee per Borg action from currently
tracked visible attackers, with native per-monster danger as the fallback
only for attackers without HURT blows. The trace keeps the two inputs.
The initial exponential has an e-folding time of four Borg actions to death.

F3 uses the contact melee subset of #759 and rounds up to complete attack
commands. When that race is unavailable, F3 starts from F2. Each usable
escape class subtracts one from the log odds. The three classes are Phase
Door, known healing or status-cure potions, and a nearby usable staircase.
These choices are calibration hypotheses.

Run `python3 tools/calibrate-death-risk.py PATH [PATH ...]` on extracted Zoo
raw shards. Legacy traces can reproduce F1 using their post-decision danger
and dungeon depth as a proxy for stop eligibility. F4 uses scikit-learn to
fit a separate logistic model per horizon, with the same seeded birth kept
in one split across arms and pilots. Fit and evaluate on distinct births.
The script scores the three heuristic formulas on the same held-out rows
whenever F4 is available. Its stop table shows both first crossings and any
crossing within the death window. A survivor can count at most one stop.

The three retained pilots cover 450 cells and 19 deaths. They predate the
combat and escape fields. The F1 report is on [#790](https://github.com/diegoami/borg-reborn-rs/issues/790).
F2–F4 need instrumented cells from [Zoo #534](https://github.com/diegoami/borg-zoo/issues/534).
The owner chooses a formula after that comparison and the existing `/stopscared` command is still the legacy
danger threshold.
