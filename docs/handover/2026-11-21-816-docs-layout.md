### Checked by doing it (fresh container, Ubuntu)

`scripts/setup.sh`; `BORG_IMPL=rust harness/build.sh` (53 s);
`harness/run.sh /tmp/run1 1 0 0 5000 menu`; `./watch-borg.sh
--build-only`; and the watched game under Xvfb: birth, then Ctrl-Z,
warnings, `y`, `z`. The Borg walked off the stairs toward a shop. Found
along the way, now in the README:

- **Without `.angband-reborn/user/borg.txt`, a watched game plays the frozen
  reborn core.** The core writes a default borg.txt with no
  `borg_reborn_core`, and `parse_core_selector` reads a missing value as
  reborn (`borg-reborn-rs/src/borg.rs:330`). `watch-borg.sh` does not copy
  `harness/borg.txt`, so the README has the user copy it with the scary
  list. A launcher that copies it when absent would remove the trap: a
  code change, so not done here.
- `harness/run.sh` exits 1 unless borg-cemetery is beside the repository
  **at `death-tools-pin.txt`** (a newer head is refused).
- The game needs a UTF-8 locale.
