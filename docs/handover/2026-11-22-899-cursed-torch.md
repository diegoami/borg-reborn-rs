# #899 Keep a harmful light equipped until it can be replaced directly

The harmful-curse branch now wields a powered, uncursed spare directly.
Without a usable spare it leaves the light equipped for the existing
decursing and shopping paths. The general equipment-removal branch also
leaves that light slot alone. The per-item and per-level retry limit covers
refused swaps as well as refused take-offs.

On build `a6e30cd1` at the shipped settings, Elf Blackguard seed
1965910635 and Kobold Druid seed 653243095 both reached the exact 100,000-turn
cap. The fixed key streams match the original replays up to the first
take-off, when both characters instead wielded a usable spare.
The [original replays](https://github.com/diegoami/borg-cemetery/pull/106)
contain the two deaths. All three default-core smoke runs match the
reference. The unit regression covers no spare, unusable spares, an
unrelated cursed slot, a refused swap and a successful swap.

starts it under RULES 20.
