## 2026-11-23: a general movement-loop detector (#1153)

**Done.** `loop_breaker`, compiled 0 and **shipped 1** (owner,
2026-11-23: "why would you ship it off by default, no loopbreaker"), in a
new module of ours, `borg_loop.rs`.
- **Detect.** Every dungeon think records the Borg's grid when it moved,
  with the grids of the map it knows, per level. A loop is the last 16 moves
  among at most 3 grids, the map unchanged, and no danger above a quarter of
  the HP.
- **Break**, before any flow continues: a walk to a staircase; else a walk
  under boosted avoidance; else the loop's grids closed for 20 thinks
  (`step_banned` in `borg_play_step`). The walks are committed
  (`commit_loop_walk`, a `BraveWalk` with `from_loop`), so the next thinks
  continue them.
- **Note.** The last decisions chosen (`core_trace::recent_choices`), so
  each pair found can still get its own fix.

The rules are in `docs/CALIBRATION.md`.
