## 2026-11-18: CI installs only missing apt packages (#585)

Owner: "that CI is killing us, make it faster". In run 44308867613,
`apt-get update && apt-get install` took 535 s in the rust job and 315 s in
the engine job (9-84 s in other runs): a slow package mirror, hit by every
job for packages the runner image mostly has already.

- **`.github/actions/apt-install`:** a composite action used by the rust,
  engine and recorder jobs. It installs only the packages `dpkg-query` reports
  missing, without `apt-get update`, and runs `apt-get update` only if that
  install fails. It also removes `/var/lib/man-db/auto-update`, so package
  triggers don't rebuild the man-db index.
- **With #577's skip of the full suite,** a PR that touches only `borg-core/`,
  settings or docs should now take about 3-5 minutes instead of 12-16.
- **Left:** `cargo install bindgen-cli` (33 s, rust job) builds from source on
  every run; a cache or a prebuilt binary would save that too.
