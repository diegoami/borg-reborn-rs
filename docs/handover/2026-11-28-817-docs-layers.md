everything in it. It should say how to get the game with the Borg (a
release package, or Angband patched with the Borg and built), then link to

## Found

- **`watch-borg.sh --build-only` failed on a fresh checkout.** It writes
  `build/watch.cmake.log`, but nothing had made `build/` yet (it worked
  after `harness/build.sh` had run once). The fix is one line.
- **No release is published yet.** `v0.1.0-alpha.1` is a draft, so the
  README says to build from source until one is published.
- **The game cannot be patched separately.** A downloaded Angband cannot be
  patched into a Borg on its own: the Borg also needs our frontend, the
  Rust library and the CMake build. So the README explains the honest
  route: Angband is included, and the build patches a copy.
