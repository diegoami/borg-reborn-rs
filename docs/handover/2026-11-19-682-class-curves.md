## 2026-11-19: class curves for Phase Door and flasks of oil (#682)

Owner: a class-based curve for Phase Door and flasks of oil, the same way
healing has one. "No reserve, we only modify the curve." The values were
typed by the owner.

- **Code** (`borg-core/src/borg_town_capability.rs`, two new params):
  - `town_phase_curve_scale_percent` stretches Phase Door's curve. Weight
    and demand scale together, as `town_heal_curve_scale_percent` does.
  - `town_oil_curve_scale_percent` weights each flask's thrown damage on
    the shared ATTACK curve. Oil has no curve of its own, and giving it one
    would change the plan schema and today's play. At 100 both are today's
    plan.
- **Shipped values** (`harness/borg_<class>.txt`, folded into `borg.txt`),
  Phase Door % / oil %: Warrior 75/100, Mage 175/100, Druid 175/150, Priest
  125/150, Necromancer 175/100, Paladin 100/125, Rogue 125/125, Ranger
  150/50, Blackguard 50/100. The owner also set Blackguard's healing to
  100/200, the same as Rogue and Ranger.
- **Local check** (18 classes-18 starts, 100,000 turns, on main `e5cc5469`):
  - with both scales at 100, the keys match main in 18 of 18 games;
  - with the owner's values: 0 deaths (main 1), sum of max CL 103 (103),
    sum of max DL 38 (39).

  Flasks bought rise with the oil scale: Priests 135 → 147, Paladins
  70 → 100, Rogues 34 → 163, Blackguards 62 → 90. Eighteen games measure
  nothing (RULES 14).
- **smoke-borg-rs re-recorded** (`scripts/rerecord-smoke-borg-rs.sh`): 1/3
  games identical to the old reference.
- **Checked:** fmt, clippy `-D warnings`, `cargo test --workspace --exclude
  borg-core`, `cargo test --release -p borg-core` (467 passed), the class
  files check, `check-param-citations.py` (2196 entries, 0 wrong).
