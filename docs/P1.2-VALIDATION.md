```sh
BORG_CORE=borg-rs BORG_CORE_OVERRIDES=off BORG_PARAM_DANGER_MAXIMUM=1 \
  harness/run.sh harness/out/danger-cap 1000 0 0 100000 menu
```

`environment`. The first different keys.log record is line 945 at turn 4430:


`d1/2` in the override, at the same recorded position and HP. Default play
finishes alive at turn 100006, CL8, maximum depth 5; the override finishes

is a functional test, **not a proposed profile or evidence of improvement**.
The named per-think decision trace remains task #222.

play change: keys and state logs remain identical to the default. That
negative functional result is retained. Parser tests independently verify
file/environment loading for danger and escape settings.
