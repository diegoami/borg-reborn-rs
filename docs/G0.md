## The stalls found, and fixed

The first G0 full-suite attempt was not accepted as a pass. It had
**53,497 `Hold` actions**, seven long starvation cases and two effect
violations. The trace showed Explore alternating with its cooldown
without making progress. One arrival map was an enclosed, fully known
room containing only an up staircase:

1. the frontier already underfoot was still treated as a destination,
   although `step()` correctly returned “at goal”;
2. an exhausted frontier could select empty Explore again instead of
   Descend's reroll;
3. Descend walked to the up staircase to reroll but never issued
   `Ascend`;
4. level changes, like store actions, could make checked progress without
   advancing the game turn, so the refusal budget forced a spurious Hold
   after every two rerolls.

All four were fixed in `6318cd2`, with regression tests. The up/down
reroll is the already-documented escape from an exhausted level, not
stair-scumming to a target depth (GOALS principle 9).
