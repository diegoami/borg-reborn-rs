# AMBITIOUS candidate schedules (#352), NOT calibrated recommendations.
# A second hypothesis next to errands_plan.txt, from the Strategy Manual's
# depth curve (reference/c-manual/12-game-plan-by-phase.md, 12.2): steep
# early, about one dungeon level per one or two character levels to ~DL30,
# then the DL30-45 shoulder. Fighters (warrior, paladin, rogue, ranger,
# blackguard) take one level per character level; casters (and [default])
# start a little slower and catch up by DL30. From character level 3 (6 for
# casters) the cap only rises. Town visits are the core's own (supplies,
# recovery, and the M13 trip policy when it is on).
# The core's readiness and emergencies still apply under every cap, so these
# depths are limits, not forced descents. Deliberately no phase at level 50.
# max-depth (owner, 2026-11-16): each phase is a depth cap, not a route.
# The core plays as itself (its own dives, town trips, shopping) and is
# never prepared for a level below the cap (borg_no_deeper). Converted from
# the earlier loop-levels A B phases as max-depth B.
